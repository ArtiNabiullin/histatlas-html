## Важно
Wix не предоставил в текущем сеансе полный набор оригинальных внутренних карт и изображений как скачиваемые файлы. Поэтому:
- доступные изображения заданий подключены с оригинального Wix CDN;
- для карт цивилизаций сделаны самостоятельные HTML/SVG-заглушки;
- интерактивные вкладки АТЛАС/СПУТНИК, lightbox и навигация реализованы на чистом JavaScript.

Чтобы получить пиксель-в-пиксель автономную копию, нужны оригинальные файлы изображений/скриншоты всех карт и страниц либо экспорт ресурсов Wix.
